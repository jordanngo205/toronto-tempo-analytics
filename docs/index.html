Tempo LabToronto's first WNBA season, broken down with data.

About

All data comes from sportsdataverse: ESPN play-by-play and box scores, plus WNBA Stats lineups. Every page is static HTML with hand-built SVG charts and no chart library. The Python that builds each page is in the GitHub repo. The approach follows the film-and-data breakdowns of Rise of the Valkyries and the Elo work of Neil Paine.
