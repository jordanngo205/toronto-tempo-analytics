Method

Score and clock come from ESPN play-by-play. Margin is sampled every 20 seconds for the grid, and overtime is left off the grid but included everywhere else. A run is consecutive points by one team with no opposing points between them, free throws included. Elo uses K = 25, a 60-point home edge, a margin-of-victory multiplier and 40% regression to 1500 between seasons (settings tuned on 2004–2023 games and tested on 2024–2026). New teams start at 1300.
